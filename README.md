# منصة خدمة كنيسة القديس ماريوحنا المعمدان بالمعراج (مطرانية الأقباط الأرثوذكس بالمعادي)

تطبيق ويب تقدمي (PWA) مخصص لإدارة خدمة الشباب ومدارس الأحد بكنيسة القديس ماريوحنا المعمدان بالمعراج.

## المميزات الرئيسية
- **لوحة المخدومين:**
  - تسجيل الحضور والغياب الذكي بـ QR Code أثناء وقت الخدمة (من 10:30 صباحاً حتى 02:00 ظهراً).
  - دفتر الإنجاز الروحي: متابعة صلوات الأجبية (باكر، الغروب، النوم)، قراءة الإنجيل، والاعتراف والتناول.
  - استعراض المناهج والدروس وأداء الامتحانات الإلكترونية والاطلاع على الدرجات.
- **لوحة الخدام:**
  - إدارة فصول الخدمة (سنة أولى، سنة ثانية، سنة ثالثة، وفصل أليشع لإعداد الخدام).
  - مراجعة واعتماد طلبات الانضمام وتقارير الافتقاد التلقائية.
  - توليد وطباعة أكواد الـ QR للخدمة.
  - بنك الأسئلة والامتحانات (تصحيح تلقائي + شاشة تصحيح للأسئلة المقالية) ورصد الدرجات الورقية.
